# CloudDock 人工验收清单

当前本地候选版本：`2.1.0`（新增 Intel x64 构建，真机验收待完成）
目标架构：Apple Silicon ARM64 / Intel x64

自动测试无法代替真实 RAM 登录和第二台 Mac 的 Gatekeeper 流程。每个候选 DMG 发布前按下面的清单走一遍，并记录设备、日期和结果。

以下已有勾选和第 7 节记录保留历史验收结果，不代表当前候选已经重新完成人工验收。各版本结果见第 6 节的日期记录。

- [ ] ARM64 与 Intel x64 安装包分别通过校验，主程序及 Electron 框架架构与文件名一致。
- [ ] Intel Mac 上完成安装、启动、RAM 登录、控制台切换、退出与重启恢复。

- [x] `hdiutil verify` 通过。
- [x] DMG 可以挂载，CloudDock 可以复制到本地安装目录并启动。
- [x] 主可执行文件是 ARM64。
- [x] 安装包没有 Developer ID 签名和自动更新模块，ad-hoc 完整性签名通过 `codesign --verify --deep --strict`。
